# notes — valid palindrome

**approach:**

**time complexity:** O(n) time, O(n) space
**space complexity:** O(n) time, O(n) space

**gotchas / follow-ups:**
Keep only letters and digits, lowercase them, compare with the reverse. O(n) time, O(n) space. An empty string is a palindrome. A two-pointer version avoids the extra list but is longer to write.
